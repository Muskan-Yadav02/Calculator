# 🧮 Calculator App
A simple and user-friendly **Calculator Application** designed to perform basic mathematical calculations quickly and accurately. This project provides an easy-to-use interface for performing everyday arithmetic operations.

## ✨ Features
* ➕ **Addition** – Add two or more numbers.
* ➖ **Subtraction** – Calculate the difference between numbers.
* ✖️ **Multiplication** – Multiply numbers easily.
* ➗ **Division** – Divide numbers to perform calculations.
* 🎨 **Simple Interface** – Clean and user-friendly design.
* ⚡ **Quick Calculations** – Perform mathematical operations efficiently.

## 🛠️ Technologies Used
* HTML
* CSS
* JavaScript

## 🚀 Getting Started
Follow these steps to run the project on your local machine.
### 1. Clone the Repository
```bash
git clone https://github.com/Muskan-Yadav02/Calculator.git
```
### 2. Navigate to the Project Directory
```bash
cd Calculator
```
### 3. Open the `calculator.html` file in your web browser

## 🎯 Project Objective
The objective of this project is to develop a simple calculator that makes everyday mathematical calculations easy while providing practical experience in application development and user interface design.
